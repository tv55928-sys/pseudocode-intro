# Math Code Lab

A no-login coding page for Ontario math (MTH1W, strand C2: Coding). Students read, predict, run and change pseudocode in the EQAO style, and compare two linear relations to find where they meet.

## Language supports

- **Short, clear sentences** in every task, hint, error message and practice question.
- **My language menu.** Students choose from 17 languages. Words with a dotted line show a picture, an English meaning and the word in their language, and can be read aloud. Buttons and section titles also show the translated word.
- **Whole-page translation.** On this page, Chrome's built-in "Translate" works too. All code is marked so that it stays in English, as on EQAO.
- **Neutral contexts.** The tasks use renting a hall, phone plans and moving trucks. Nothing assumes a grade, an age, or a holiday or custom.
- **Learning supports:** Read aloud (with a slow voice), Bigger text, colour-coded code, a picture glossary for each task, one step at a time, hints, sentence frames and "Step through" memory boxes.

The translations are single words for support, not full translations. Ask students to tell you if a word looks wrong.

## Safety

The runner is locked down. It turns off imports, JavaScript access and network modules, stops long-running programs, and limits output. A Content Security Policy blocks all outside connections except Google Fonts. Saved work clears itself after 12 hours, and students can press "Clear my work". Skulpt 1.2.0 (MIT licence) is built into `index.html`.

## Use it

1. In a GitHub repository, choose **Add file → Upload files**.
2. Upload `index.html` and this README, then choose **Commit changes**.
3. Turn on GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.

GitHub Pages sites are public: anyone with the link can view the page.
